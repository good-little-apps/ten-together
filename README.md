# Ten Together public site

Static, dependency-free overview, support and privacy pages for Ten Together.
Same layout and stylesheet as the other Good Little Apps sites, recoloured.

## Production URLs

- Overview: `https://good-little-apps.github.io/ten-together/`
- Before reading (guide for parents of 2- to 4-year-olds): `https://good-little-apps.github.io/ten-together/before-reading.html`
- Support: `https://good-little-apps.github.io/ten-together/support.html`
- Privacy: `https://good-little-apps.github.io/ten-together/privacy.html`

## Deployment

The contents of this folder are the root of the public repository
`good-little-apps/ten-together`, served by GitHub Pages from branch `main`,
folder `/`. To publish a change, copy this folder's files to that
repository and push.

Keep `privacy.html` in step with `ios/Sources/Analytics.swift`, the App
Store privacy label and the listing's privacy bullets.
